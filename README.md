# Algorithm Analysis

Simple C++ project implementing and benchmarking common sorting and selection algorithms.

## Features
- Quick\-sort, Merge\-sort, Selection/Bubble/Insertion Sort, Quickselect, Median\-of\-medians
- Benchmark harness execution time
- Random test set generator

## Requirements
- macOS (tested)
- C++17 compatible compiler
- `cmake` 3.15+

## Build
```bash
mkdir -p build
cd build
cmake ..
cmake --build .
